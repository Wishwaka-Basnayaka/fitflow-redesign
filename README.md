# FitFlow Redesign

FitFlow is a cross-platform fitness and wellness application.

## Technology Stack

- Frontend: Flutter
- Backend: NestJS
- Database: PostgreSQL
- Authentication: Supabase Auth
- Cache: Redis
- AI/ML: Python + FastAPI
- Real-time: WebSocket

## Project Structure

- frontend/ - Flutter application
- backend/ - NestJS backend
- ai-service/ - AI/ML microservice
- docs/ - Project documentation
